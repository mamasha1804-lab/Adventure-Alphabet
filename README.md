# Adventure Alphabet

Интерактивный сайт «Учимся с Ларисой Коротаевой» для изучения английского алфавита детьми младшего школьного возраста.

## Что уже работает

- 4 экрана выбора букв: A–F, G–M, N–S, T–Z;
- отдельный экран каждой буквы;
- 3 задания для каждой буквы: Listen & Choose, Find the Letter, Match It!;
- во втором задании ребёнок ищет предметы, соответствующие текущей букве;
- в третьем задании нет подсказок: нужно самостоятельно сопоставить слово и картинку;
- озвучивание английских слов средствами браузера;
- звёзды и финальная награда;
- переход к следующей букве;
- сохранение пройденных букв в браузере через localStorage;
- экран «Достижения» с прогрессом A–Z;
- отметка пройденных букв прямо на витрине;
- адаптация под компьютер, планшет и мобильный экран;
- навигация по разделам сайта;
- workflow для GitHub Pages находится в `.github/workflows/pages.yml`.

## Структура

`index.html` — разметка сайта.  
`styles.css` — визуальный стиль и адаптивность.  
`script.js` — логика алфавита, игр, озвучивания и прогресса.  
`.github/workflows/pages.yml` — автоматическая публикация после включения GitHub Pages в настройках репозитория.

Сайт статический и может запускаться напрямую из `index.html`.
